# 한끗: PC 화면 통일 (의도)

2026-11-22 밤 확정. 사용자 말: "일단 해 보고, 보고 나서 수정하자." 아래 배치로 먼저 만들고, 미리보기와 캡처를 보면서 고쳐 나가요.
처음 의도 문서(`docs/intent/hankkeut-redesign.md`)의 "PC 나머지 화면: 가운데 한 칸에 새 모양만"은 이 문서로 바뀌어요. 색은 `docs/intent/hankkeut-color.md`(보라 #5B3DF5, 바탕 #F2F4F6)를 따라요.

## 목표 (Why)
- 팀원 지적: 지금 PC에서 시작·결과·근무시간 바꿔 보기·두 제안 비교 4개 화면만 1080px로 넓고, 나머지는 560px 기둥이라 휴대폰 화면 같아요. 화면을 넘길 때 폭과 위쪽 막대 위치가 바뀌어 일관성이 없어요.
- 모든 화면을 같은 PC 틀 안에 넣어 하나의 서비스처럼 보이게 해요.

## 대상 (Who)
- PC로 볼 가능성이 높은 심사위원

## 원칙
- PC(1024px 이상)에서 모든 화면이 같은 1080px 틀과 같은 왼쪽 선을 써요.
- 위쪽 막대(로고 또는 뒤로·진행 막대)는 모든 화면에서 같은 폭과 위치예요.
- 아래 고정 버튼 줄은 모든 화면에서 같은 자리(틀의 오른쪽 아래)예요. 시작 화면은 지금처럼 왼쪽 칸 안에 주 버튼을 둬요.
- 화면을 억지로 꽉 차게 늘리지 않아요. 글과 입력 칸은 읽기 좋은 폭을 유지하고, 남는 자리에는 같은 화면의 보조 내용을 옮겨요.
- 휴대폰 배치와 순서는 지금과 똑같아요. PC에서만 칸을 나눠요(마크업 순서를 지키거나 CSS 그리드 자리 지정으로).

## 화면별 배치 (PC)
| 화면 | 배치 |
|---|---|
| 시작, 결과, 근무시간 바꿔 보기, 두 제안 비교 | 지금 두 칸·나란히 그대로 |
| 내 상황 질문 6개, 공고에 없는 것 묻기, 조건 확인 질문 | 왼쪽: 단계 표시·질문 제목·설명·'왜 물어보나요?' / 오른쪽: 고르는 버튼·숫자 입력·공고 원문 인용·계산 과정 |
| 읽은 조건 | 왼쪽: 조건 목록 / 오른쪽: 표시 설명(점 범례)·공고 원문 보기 |
| 공고 올리기 | 왼쪽: 올리는 방법 3줄 / 오른쪽: '공고가 아직 없다면' 예시·'이런 공고도 읽어요'·AI 안내 |
| 글 붙여넣기, 사진으로 올리기 | 왼쪽: 제목·입력 칸(글 상자 또는 사진 고르기) / 오른쪽: 찍는 법·지울 것·AI 안내 |
| 예시 고르기 | 예시 4개를 2개씩 나란히 |
| 저장한 제안 | 제안 카드를 나란히(최대 3개)와 '비교할 제안 더하기' |
| 문구 만들기 | 왼쪽: 제목·문구 상자 / 오른쪽: 요청 종류 고르기·다른 시간으로 바꾸기 |
| 시작 전 준비 | 왼쪽: 챙길 것 목록(물어볼 것·신고할 것·확인할 것) / 오른쪽: 물어볼 곳·계산 근거와 출처 |
| 개인정보 처리 안내 | 왼쪽: 무엇을 어디로 보내나요 / 오른쪽: 꼭 지켜 주세요·보관과 지우기·만든 사람 |
| 직접 입력, 읽는 중, 공고가 아닐 때, 사진을 못 읽었을 때 | 한 칸 그대로, 다른 화면과 같은 왼쪽 선에 맞춤(가운데 정렬 아님) |
| 아래에서 올라오는 창 | 그대로 |
