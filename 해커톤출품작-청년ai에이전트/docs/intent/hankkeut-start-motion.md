# 한끗: PC 시작 화면에 떠다니는 동전·지폐 그래픽 (의도)

2026-11-23 새벽 2시 인터뷰로 확정했어요. 사용자 말: "시작화면에 모션그래픽을 넣고싶은데 괜찮을까?"
색은 `docs/intent/hankkeut-color.md`(보라 #5B3DF5, 바탕 #F2F4F6), PC 배치는 `docs/intent/hankkeut-pc-layout.md`를 따라요.

## 목표 (Why)
- 지금 시작 화면은 들어올 때 0.3초만 움직이고(떠오르기·형광펜·영수증 출력·돈 막대 채우기) 멈춰서 정적으로 보여요.
- PC로 처음 들어온 사람에게 멈춰 있는 페이지가 아니라 '살아 있는 서비스'라는 첫인상을 주고 싶어요. 설명보다 분위기가 먼저예요.
- PC는 여백이 많아서 그래픽을 둘 자리가 있어요.
- 대회 제출 마감(2026-11-23 17:00) 전에 바꿀 수 있는 마지막 때예요.

## 대상 (Who)
- PC로 처음 들어오는 심사위원

## 성공 기준
- 1024px와 1440px PC 시작 화면에서 그래픽이 은은하게 계속 움직이고, 제목·버튼·예시 영수증·글과 겹치지 않아요.
- '움직임 멈춤' 버튼으로 멈추고 다시 켤 수 있어요. 키보드로도 되고, 누르는 곳은 44px 이상이에요.
- 휴대폰 375px 시작 화면은 지금과 같아요(바꾸기 전 캡처와 픽셀 비교).
- 80개 화면(375·1440px)에서 가로 넘침·콘솔 오류 0, 글자 대비 4.5:1 이상, `cd munteok && npm test` 전체 168건·통과 168건 그대로.
- 캡처로는 움직임이 안 보이니까, 12:00 팀 결정 전에 팀이 움직임을 볼 수 있게 PC 시작 화면 짧은 화면 녹화(또는 허락받은 배포 주소)를 준비해요.
