# 한끗: PC 다른 화면 여백에 떠다니는 동전·지폐 + 질문 화면 오른쪽 칸 가운데 (의도)

2026-11-23 새벽 3시쯤 인터뷰로 확정했어요. 사용자 말: "이거 둥둥 떠다니는걸 시작화면말고 메뉴마다 띄워줄 수 있어? 시작화면은 내가 따로 하고싶은게 있어", "왜 오른쪽 선택하는게 위로 올라가있는거야? 중앙배치하면 안돼?"
`docs/intent/hankkeut-start-motion.md`의 "PC 시작 화면에만"과, 하지 않을 것의 "시작 화면 말고 다른 화면에 그래픽 넣기"는 이 문서로 바뀌어요. 그림 모양(한끗 보라로 직접 그린 동전·지폐), 움직임 방식(transform만, 은은하게 계속), '움직임 멈춤' 버튼과 동작 줄이기 규칙은 그 문서 그대로예요.
색은 `docs/intent/hankkeut-color.md`, PC 배치는 `docs/intent/hankkeut-pc-layout.md`를 따라요.

> **바뀜 (2026-11-23 10:40):** 사용자가 "시작 화면도 다른 메뉴들처럼 상하좌우 모션그래픽 넣어줘"라고 해서, 시작 화면(PC 1366px 이상)에도 같은 자리에 같은 동전·지폐 4개를 띄워요. 시작 화면의 '따로 하고 싶은 것'은 배경 영상(`docs/intent/hankkeut-bg-video.md`)이었고 그대로 둬요. '움직임 멈춤'은 하나로 영상과 동전·지폐를 함께 멈춰요. 아래 표의 '시작 화면' 줄과 하지 않을 것의 '시작 화면은 그림·버튼을 빼는 것까지만'은 이 결정으로 바뀌어요.

## 목표 (Why)
- 그림이 시작 화면에만 있으면 화면을 넘기는 순간 사라져서 서비스가 갑자기 멈춘 것처럼 보여요. 화면마다 있다 없다 하지 않고 모든 화면에서 같은 자리에 떠 있어, 하나의 살아 있는 서비스로 보이게 해요.
- 시작 화면은 사용자가 따로 하고 싶은 게 있어서 비워 둬요(그림·버튼을 빼고 전 모습으로).
- PC 질문 화면에서 오른쪽 고르는 칸이 짧으면 위에 붙고 '다음' 버튼까지 아래가 크게 비어 보여요. 왼쪽 글 묶음과 무게를 맞춰요.

## 대상 (Who)
- PC로 들어오는 심사위원
