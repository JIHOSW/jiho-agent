# 한끗

새로운 일을 시작하는 청년이 소득과 지원의 변화를 미리 이해하고, 근무조건 결정부터 필요한 확인·신고 준비까지 할 수 있도록 돕는 서비스.

## 실행

제출 주소: https://hankkeut-app.vercel.app (이 폴더를 Vercel에 올린 것). 서비스 전체 설명은 [저장소 맨 위 README](../README.md)에 있다.

화면은 설치가 필요 없다. 저장소 맨 위 폴더에서 이 폴더를 정적 웹 서버로 연다.

```bash
python3 -m http.server 8770 --directory munteok
```

- 앱: http://localhost:8770/
- 규칙 엔진 테스트: http://localhost:8770/tests/

터미널 테스트: 이 폴더에서 `npm test` (Node.js 20 이상, 설치 없이 실행). 2026-11-23 기준 전체 172건 통과.

`index.html`을 파일로 직접 열면 규칙표를 불러오지 못한다. 반드시 서버로 연다. 정적 서버에는 서버 함수가 없어 AI 공고 읽기는 실패 안내를 보여 주고, 예시와 직접 입력으로 동작한다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `data/rules.json` | 규칙표. 기준 금액, 근거 출처, 적용 연도, 확인일, 확인 수준 |
| `js/engine.js` | 계산 엔진. 급여, 제도별 판정, 대안 탐색. 화면과 분리된 순수 함수 |
| `js/app.js` | 화면 흐름 |
| `js/samples.js` | 시연용 가상 샘플 3개 |
| `js/config.js` | AI 서버 주소, AI 공고 읽기 끄기(`AI_OFF`) 설정 |
| `js/bgvideo.js`, `css/bgvideo.css`, `media/` | PC 첫 화면 배경 영상 |
| `css/style.css` | 휴대폰 우선 화면 스타일 |
| `api/extract.js` | AI 공고 읽기 서버 함수 (Vercel) |
| `tests/` | 엔진 기대값 테스트(`engine.test.js`, 브라우저 `index.html`·터미널 `run.mjs`), AI 추출 시험(`extract-eval.mjs`) |

## 현재 되는 것

- 가상 샘플 3개와 직접 입력으로 시작부터 결과까지 전체 흐름
- 추출 확인(항목별 확정·추정·확인 필요), 추가 질문, 내 상황 입력
- 제도 4개 판정: 부모 연말정산 공제(현행·개정안 병기), 건강보험 피부양자, 구직촉진수당, 주 15시간 기준
- 제안 비교: 제안을 3개까지 저장해 같은 규칙으로 계산하고, 한 달에 남는 돈, 일한 시간당 금액, 기간 전체 금액, 확인 안 된 조건 수를 나란히 보여준다. 기준마다 앞서는 제안만 표시하고 결론은 내리지 않는다
- 제안마다 시작 전에 고용주에게 물어볼 질문을 만든다(지급 방식, 주휴수당, 기간 등)
- 월별 누적 소득, 근무조건 비교(받은 제안, 내가 가능한 최대 시간, 그 사이의 변화 지점), 남는 돈이 줄어드는 구간과 가장 많이 남는 시간 표시
- 행동(근무 확대, 시간 조정, 급여 조건 확인, 그대로 수락)을 고르면 확인 질문을 넣어 문구를 조합. 신고 회피로 읽힐 표현은 테스트로 막는다
- 시작 전 준비 체크리스트: 고용주 확인 질문, 신고할 곳과 시점, 원문 확인이 필요한 것
- 변화를 급여 증가, 수당 감소, 자격 확인 필요, 소득 신고 필요로 구분해 표시. 기준을 넘었다는 사실과 그 변화의 유불리를 따로 보여준다
- 요약 금액은 "남는 돈"(번 돈에서 보험료·세금과 줄어드는 정부 지원을 뺀 돈)이며 계산에 넣은 것과 넣지 않은 것을 함께 밝힌다. 부모의 세금 증가액은 근거가 부족해 계산하지 않는다
- 근거와 다음 행동, 해당 없는 제도와 범위 밖 제도 안내, 최저임금 미달 경고

## AI 추출 (api/extract.js)

| 항목 | 내용 |
|---|---|
| 하는 일 | 공고 텍스트나 사진에서 시급, 주당 근무시간, 시작 월, 개월 수, 소득 종류를 뽑고 항목마다 확정·추정·확인 필요와 원문 근거를 붙인다 |
| 하지 않는 일 | 기준선 판정과 금액 계산. 그 일은 브라우저의 `js/engine.js`가 한다 |
| 모델 | `claude-opus-5-5`, effort `low`, 구조화 출력(JSON 스키마)으로 형식을 고정 |
| 안전장치 | 텍스트 4,000자, 사진 3장·장당 약 3MB 제한. 범위를 벗어난 값은 버리고 확인 필요로 바꿈. 일자리 공고가 아니면 거절(422). 입력 내용은 서버에 저장하지 않음 |
| 실패 시 | 화면에 이유와 재시도 안내를 보여주고 직접 입력이나 샘플로 넘어갈 수 있음 |
| 사진 | 브라우저에서 긴 변 1600px JPEG로 줄여 보냄 |

실행 위치는 Vercel 서버 함수다. Vercel 프로젝트의 Root Directory를 `munteok`으로 두고 환경 변수 `ANTHROPIC_API_KEY`를 넣는다(다른 주소에서 부르려면 `ALLOWED_ORIGINS`, 작업 공간에 묶이지 않은 조직 키면 `ANTHROPIC_WORKSPACE_ID`도. `api/extract.js` 맨 위 주석 참고).

AI 추출 시험: `node tests/extract-eval.mjs https://hankkeut-app.vercel.app` (API 크레딧이 조금 쓰인다). 지어낸 공고 8건을 보내 기대값과 비교한다. 2026-11-23 제출 주소에서 항목 35/35, 공고 8/8.

## 하지 않는 것

- **AI의 대안 탐색**: 대안 계산은 `searchAlternatives`(엔진)가 한다. AI가 이 함수를 도구로 부르거나 결과를 설명하지는 않는다.
- **화면 6(입력 요약), 화면 9(대안 상세), 화면 11(내 기록)**: 따로 만들지 않았다. 요약은 내 상황 화면 하단에, 요청 문구는 대안 비교 화면에 넣었다.

## 규칙의 확인 수준

`data/rules.json`의 `verification` 값이 화면 표시 등급을 정한다.

| 값 | 뜻 | 화면 표시 |
|---|---|---|
| `official` | 정부·법령 원문을 직접 확인 | 확정. 금액, 판정, 대안에 사용 |
| `secondary` | 2차 자료 또는 원문 수치로 계산한 값 | 추정. 금액에 쓰되 큰 숫자에서 빼고 따로 표시 |
| `unverified` | 원문을 확인하지 못함 | 확인 필요. 금액, 판정, 대안에 쓰지 않고 "추가 확인 항목"으로만 안내 |

규칙표 버전 2026-11-20 기준으로 원문 확인이 남은 항목(화면에 '추정'·'확인 필요'로 따로 표시):

| 항목 | 현재 | 확인할 곳 |
|---|---|---|
| 일용근로소득이 부양가족 소득 요건에서 빠지는지 | unverified | 국세청 126 |
| 사업소득을 경비를 뺀 금액으로 보는지 (부모 공제, 피부양자) | unverified | 국세청 126, 국민건강보험공단 1577-1000 |
| 부모 공제 개정안(정부 세제개편안 2026.8)의 국회 통과 여부와 적용 시점 | secondary | 국세청 126 |
| 사업소득 3.3% 원천징수율 | secondary | 국세청 126 |

구직촉진수당 계산식·금액, 2026년 1인 가구 기준 중위소득 60%(1,538,543원), 4대보험 근로자 요율, 한 달 소정근로시간 60시간 이상이면 직장가입자가 되는 기준은 원문을 확인해 `official`로 바꿨다.

규칙 값을 바꾸면 `tests/engine.test.js`의 기대값도 손으로 다시 계산해 고친다.

## 계산에서 가정한 것

- 한 달은 4.345주로 계산한다.
- 공고에 적혀 있지 않으면 주휴수당은 시급과 별도로 지급된다고 가정하고 "추정"으로 표시한다. 확인 화면에서 "시급에 이미 포함됨"으로 바꿀 수 있다.
- 입력값은 새로고침해도 남도록 브라우저 탭의 세션 저장소에 둔다. 탭을 닫으면 지워지고 서버로 보내지 않는다.
- 소득세(근로소득 간이세액)는 계산하지 않는다.
- 2026년 규칙으로 한 해(1월~12월)만 계산한다. 해를 넘기는 근무는 올해 분만 계산하고, 빠진 개월 수를 화면에 알려 준다. 2027년 기준은 최저임금(10,700원)만 확정되어 안내용으로만 쓴다.
- 대안 탐색은 주당 근무시간만 바꾼다. 시급과 기간은 그대로 둔다.
- 야간·연장 가산수당은 계산하지 않는다.
