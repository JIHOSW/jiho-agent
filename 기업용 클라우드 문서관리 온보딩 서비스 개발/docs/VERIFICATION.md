# 검증 기록 · 2026-11-04

- Node 테스트 21개 통과. 실패를 먼저 확인하고 구현·수정 후 통과를 확인했습니다.
- TypeScript `tsc --noEmit` 통과.
- Sites `build-site.mjs` 프로덕션 빌드 통과. lucide import 최적화 생략·Vinext 경로 분류 안내는 빌드 실패가 아닙니다.
- 로컬 HTTP: `/` 200, `/api/status` 200/configured=false, 키 없는 `/api/analyze` 503/KEY_MISSING.
- 브라우저: 데스크톱 1440×1000 및 기본 좁은 화면 관찰. 기록 부족 선택 시 분석 변화, 안내문 수정·저장, 작업 등록·완료, 새로고침 후 저장 유지, 키 미설정 안내를 확인했습니다.
- 독립 코드 검토: AI 조치 ID가 바뀔 때 동일 작업 중복 가능성을 재현했습니다. 같은 고객의 진행 중인 작업은 정규화한 제목도 비교하도록 수정하고 회귀 테스트를 추가했습니다.
- 고객 추가 업데이트: 새 고객 등록·선택·0% 표시, 연결 작업 등록, 새로고침 후 유지, 중복 회사명 차단을 브라우저에서 확인했습니다. 기존 v1 저장 형식 호환·서버 프로필 검증·샘플 고객 덮어쓰기 거부·가짜 시스템 기록 필드 제거는 자동 테스트로 검증했습니다. 독립 코드 검토에서 주요 추가 문제는 발견되지 않았습니다.

## 한계

- API 키가 없어 실제 OpenAI 응답·청구·실측 품질은 검증하지 않았습니다. 외부 응답 계약·오류 처리는 테스트용 응답으로 확인했습니다.
- 스크린샷과 포커스 구조만으로 접근성 전체 준수를 보장하지 않습니다. 실제 사용자·스크린리더 검증은 남아 있습니다.
- 인용 ID 존재 검사는 의미적 정확성을 보장하지 않습니다.
- 최초 제공 HTML은 file URL 보안 정책으로 렌더링 검증하지 못했습니다. 브라우저 검증은 새로 구현한 HTTP 앱을 대상으로 수행했습니다.
