# 구매 혁신 HTML 제안서 제작 계획

요청: 아이마켓코리아 구매·공급망 솔루션을 제조 고객에게 영업하는 AI 실습용 HTML 발표, 정확히 10장.

## 구성과 디자인
1. 구매를 연결하는 플랫폼: 생성한 3D 공급망 이미지와 제안 요약.
2. 고객의 구매 과제: 분산된 구매의 병목, 검증할 현장 가설.
3. 선택의 근거: 공식 IR의 운영 규모와 공식 직무·서비스 역량.
4. 제안 구조: IMK Mall + 구매 전문인력 + 물류 운영.
5. 구매 흐름: 단계별 클릭 가능한 제안 데모.
6. 우선 적용: 반복 구매 / 비정형 소싱 / 지출 가시화의 역할별 가치.
7. 가치 산정: 가정값을 바꾸는 Chart.js 시뮬레이터, 현금 절감과 업무 여력 분리.
8. 도입 계획: 제안 일정 8주, Chart.js 가로 범위 막대.
9. 운영·계약: 연동·권한·예외 대응, 가격과 세부 기능은 협의 사항.
10. 다음 결정: 파일럿 범위와 검증 항목, 출처 패널.

조선굴림체를 로컬 탑재. 밝은 회청색, 코발트 원, 반투명 유리, 민트 포인트로 디자인레퍼런스를 재해석. 데스크톱 16:9, 모바일 세로 카드. 단어 단위 줄바꿈, reduced-motion, 키보드/터치/전체화면/목차/발표 노트/인쇄 제공.

## 실행과 검증
- [ ] HTML/CSS/JS와 이미지·폰트·Chart.js 번들 구성.
- [ ] 다운로드 가능한 단일 HTML 생성. 원본 자료는 수정하지 않음.
- [ ] 10장, 로컬 링크, 수식, 차트 데이터, JS 구문 확인.
- [ ] 브라우저에서 각 장의 화면과 전환·호버·시뮬레이터·모바일·인쇄 확인.
- [ ] Sites 소스 동기화 및 비공개 배포, 성공 URL 확인.

출처: 제공 PDF·리포트 이미지·디자인레퍼런스; 공식 직무소개, 회사 소개, 홈페이지, 2025 4Q IR. 리포트 이미지의 연간 매출 3조 5,444억과 공식 IR의 3조 544억은 상충하므로 공식 IR을 채택. 고객의 실제 구매 지표와 상용 기능 범위·가격은 미제공. 모든 비용/효과/일정은 제안 가정으로 표기. 잘린 이펙트 URL은 검증할 수 없어 자체 모션 적용.
