# Switchboard · 에이전트 관제 대시보드

Claude Code로 구성한 에이전트 팀(기획팀 · 공격팀 · 보강팀 · 블로그/카드뉴스 자동화팀)과 수석 비서실장(오케스트레이터)의 구조와 작업 흐름을 한 화면에서 보여 주는 시연용 대시보드입니다.

- **단일 파일**: `index.html` 하나에 Tailwind CSS(v3.4.17, 미리 컴파일해 인라인)와 Vanilla JS가 모두 들어 있습니다. 설치나 빌드 없이 브라우저에서 바로 열립니다.
- **화면 4개** (`1`~`4` 키 또는 `#workflows` `#traces` `#usage` `#agents` 해시로 이동)
  1. **Workflows**: 비서실장 중심 연결 그래프, 선을 따라 움직이는 데이터 패킷, 이벤트 로그
  2. **Traces**: 실행별 간트 타임라인 (보라 = 에이전트 추론, 청록 = 도구·렌더링, 호박색 = 사람 승인), ▶ 재생
  3. **Usage**: 시간 단축률 · 월간 토큰 · 지적 해결률 게이지, 사람 24시간 vs 에이전트 4분 48초 비교
  4. **Agents**: 팀 조직도와 실시간 상태, 운영 원칙
- **배포**: Netlify Drop(https://app.netlify.com/drop)에 이 폴더를 끌어다 놓으면 바로 배포됩니다.

> 화면의 수치는 시연용 예시 데이터입니다. 사람 작업 시간은 하루 8시간 × 3영업일 기준 추정치입니다.
