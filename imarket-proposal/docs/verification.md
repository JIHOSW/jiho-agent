# 검증 기록

- 10장과 각 장 발표 노트 확인.
- 1440×900에서 10장 전체 시각 검토. 1366×768에서 전체 10장의 세로 넘침과 화면 밖 본문 없음.
- 390×844 모바일에서 전체 10장 확인. 차트 컨테이너의 최소 너비 문제를 수정하고 재검사: 본문 가로 넘침 없음. 표지의 원형 장식은 의도적으로 영역 밖에서 잘림.
- 조선굴림체 로딩, 생성 이미지 로딩, 세 차트 캔버스 렌더링 확인.
- 목차로 임의 슬라이드 이동, 이전/다음, Home/End 키, 발표 노트, 출처 모달, 체크리스트 체크 확인.
- 구매 단계 탭 클릭과 탭 키보드 탐색 확인.
- 시뮬레이터 기본값 3.00억 / 0.50억, 최댓값 10.00억 / 1.50억, 최솟값 0.20억 / 0.05억 확인. 업무 여력은 비현금으로 구분.
- Chart.js 전역 애니메이션 기본 객체를 보존하도록 수정해 보간 오류 해결. 수정 후 새 오류 없음.
- 단일 HTML에서 폰트·이미지·Chart.js 포함 및 독립 실행 확인. 문자열 치환 시 번들 코드의 달러 문자가 변형되지 않도록 콜백 치환과 내장 스크립트 구문 검사를 추가.
- 내장 브라우저의 전체화면 요청은 환경에 따라 제한될 수 있으며 버튼은 사용 환경 안내를 제공. 브라우저 인쇄용 CSS는 포함했으나 실제 프린터/PDF 출력은 별도 검증하지 않음.

로컬 확인 명령: `node --check dist/app.js`, `node build-offline.mjs`, `node verify.mjs`.

## 2026-10-29 수정 검증

- 발표자 표기 3곳과 이미지 캡션·대체 텍스트 변경 확인.
- 1366×768에서 10장 전체 제목 중앙 정렬 및 세로 넘침 0 확인.
- 390×844에서 10장 전체 페이지 가로 넘침 및 화면 밖 본문 텍스트 0 확인.
- 카드 클릭 시 aria-pressed=true, Enter 시 false로 토글되는 것을 확인. 클릭 직후 퍼짐 효과 요소 생성 확인.
- 구매 단계 탭 이동, 절감률 5% 입력 시 5.00억 원 산출 확인. 수정본 브라우저 실행 오류 없음.
- 독립 HTML에서 포함된 새 정렬·모션 스타일과 스크립트의 구문 검사 통과.

## 표지 단순화 수정 검증

- 공유 헤더의 실습 배지 삭제. 모든 슬라이드에서 동일 헤더 사용.
- 공식 홈페이지의 MRO 사업 이미지로 표지 교체. 사진 출처를 자료 패널에 반영.
- 1366×768 표지 본문 시작 Y=140px, 슬라이드 시작 Y=65px. 본문 상단 정렬, 세로 넘침 0.
- 표지 원형 장식 0개, tilt 요소 0개. 이미지 클릭 후 사진·그림 컨테이너 transform=none, 포인터 이동 변수 미변경 확인.
- 390×844에서 가로 넘침 0. 모바일 표지 시각 검토 완료. 브라우저 실행 오류 없음.
- 오프라인 파일에 공식 사진 JPEG와 표지 전용 CSS 포함. 구문·수식·이름 표기 검증 통과.

## 시인성 개선 및 모션 절제 검증

- 퍼짐 효과, 카드 반동·강조 선택, 포인터 기울임·패럴랙스 이벤트 제거. 정적 카드 클릭 시 role 없음, transform=none, 퍼짐 요소 0 확인.
- 일반 슬라이드 본문을 1366×768 기준 18px로 확대. 차트 레이블도 13px로 확대. 설명과 주석 대비 강화.
- 바깥 여백과 제목의 강제 줄바꿈을 줄이고 중간 콘텐츠 영역·표지 사진·마지막 장 핵심 문구를 확대.
- 1366×768 및 1280×720의 10장 모두 가로·세로 넘침 0. 390×844의 10장 모두 가로 넘침·본문 잘림 0.
- 구매 흐름 탭 기능, 절감률 5%일 때 구매비 절감 5.00억 원 산출 확인. 데모 하단 설명 문구가 창 안에 표시되는 것을 확인.
- 브라우저 실행 오류 없음. 새 정렬/가독성 CSS를 포함한 단일 HTML 구문과 수식 검증 통과.
