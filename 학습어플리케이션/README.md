# 잠들기 전, 투운사

자기 전 30분, 투자자산운용사 개념을 떠올리고 다시 풀어보는 모바일 학습 앱입니다.

**[별도로 운영하는 공개 앱 열기](https://touun-night-jiho-1105.day1companyk-6083.chatgpt.site)**

## 사용하기

- 설치 없이 공개 링크를 휴대폰 Safari나 Chrome으로 엽니다.
- 목·금·토 중 공부할 날을 고르고 시작합니다.
- 보기 전에 개념을 떠올리고 답을 고른 뒤, 해설·암기 한 줄을 확인합니다.
- 맞혔어도 확신이 없으면 ‘찍어서 맞혔어’를 선택합니다.
- 틀리거나 찍은 문제는 다른 문제를 사이에 두고 다시 나오며, 다음 공부에도 먼저 나옵니다.
- 30분 타이머, 일시정지, 이어 풀기, 별표, 글자 크기와 화면 색 설정을 지원합니다.

학습 기록과 개인 문제는 해당 브라우저에 저장됩니다. 기기 간 자동 동기화는 없으며, 설정에서 JSON 백업을 주고받을 수 있습니다.

## 파일과 로컬 실행

- `index.html`: CSS와 코드를 모두 포함한 파일판입니다. 다운로드해 브라우저에서 열 수 있습니다.
- `dist/`: 공개 사이트와 같은 모듈형 원본입니다.
- `tests/`: 복습 순서, 타이머 복원, 자료 가져오기와 계산 문제 검증입니다.
- `build-delivery.mjs`: `outputs/`에 파일판과 사용방법을 다시 만듭니다.

Node.js 20 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
npm run build
```

일부 휴대폰 파일 미리보기는 JavaScript를 실행하지 않으므로 공개 링크나 실제 브라우저를 이용해주세요.

## 문제와 출처

기본 72문항은 공식 교육자료의 개념을 참고해 직접 만든 연습문제입니다. 공식 기출이나 출판사 문제 복제본이 아니며, 각 문항의 개념 참고 링크와 앱 자료실에 출처가 있습니다.
금융상품·투자분석·운용전략 중심으로 구성했습니다. 세제·부동산·법규 전 범위와 최신 개정 숫자는 포함하지 않으므로 교재를 함께 확인해야 합니다.

사용 권한이 있는 교재 문제는 직접 입력하거나 JSON 팩으로 추가할 수 있습니다. PDF·사진 자동 추출과 원격 AI API는 사용하지 않습니다.

## 검증

- 자동 검사 35개 통과: 복습·재도전·확신도·일시정지/새로고침·입력 검증과 19개 계산 사례 포함.
- 360px·390px 모바일 화면과 큰 글자 설정에서 주요 흐름 확인.
- 재도전이 추가되어도 기본 문항 수는 고정하고, 같은 문항은 완료 수에 중복 집계하지 않습니다.
- JavaScript 문법 및 파일판 빌드 확인.
