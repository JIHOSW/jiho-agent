# (주)스타랩 STALAB · AX 엔지니어 신입 공고 전사본

출처: 사용자가 이전 대화에서 제공한 채용공고 스크린샷 4장을 2026-11-24 스킬 시연용으로 옮겨 적은 것. 원본 이미지는 이 저장소에 없고, 실시간 채용 상태를 다시 확인하지 않았다.

- 회사: (주)스타랩 STALAB · 반도체 테스트 시스템과 검사 시스템 개발·제조
- 직무: AX 엔지니어 신입 · Claude Code · AI 업무 자동화

## 주요 업무
- 설계·생산·영업·품질의 반복 업무 자동화: 견적 자료, 생산·품질 데이터, 사내 문서
- 사내 시스템을 Claude에 연결: MCP 서버, Agent Skills, 훅, 서브에이전트 제작·유지보수
- 관리자 콘솔, 신청 폼, 대시보드, 회사 홈페이지 등 내부 웹 도구 개발·운영
- 기존 테스터 프로그램 분석·이관에 AI 활용
- 임직원 AI 활용 지원: 사내 세미나 보조, 사용 가이드 작성

## 필수

- Git·터미널 기본 사용
