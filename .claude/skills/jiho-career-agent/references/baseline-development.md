# AX 개발 자기소개서 기본본

상태: 대화에서 합의한 다섯 항목의 흐름과 확인된 사실로 2026-11-24 복원한 기본본. 과거 제출본이나 사용자 최종 승인 원문이 아니다. 사용자가 확정본을 주면 그 문장을 우선한다.

이력서 제목: 현장 경험과 AI 프로젝트를 바탕으로 AX 개발자로 성장하고 싶은 김지호입니다

## 반복 업무를 줄일 방법을 직접 만들고 싶었습니다

고객 요청을 정리하고 제안서와 보고자료를 만들면서, 같은 내용을 옮기거나 반복해서 설명하는 데 생각보다 많은 시간이 든다는 것을 느꼈습니다. 업무를 익히는 것도 중요했지만, 이 과정을 조금 더 수월하게 만들 방법도 찾고 싶었습니다. 현장에서 아직 AI를 충분히 활용하지 못하는 일을 보며 공부를 시작했고, 지금은 직접 도구를 만들어 실행 결과를 확인하는 방식으로 경험을 쌓고 있습니다.

엔엔소프트에서는 HANDY 그룹웨어의 Linux 환경 설치와 서버 점검, 고객 문의 대응을 맡았습니다. 이후 아이리스닷넷에서는 국립문화유산연구원과 지식이음 홈페이지 고도화·유지보수 사업에 참여해 RFP 분석과 제안서, 담당자 기능회의, 화면설계서와 메뉴구조도 작성에 관여했습니다. 시스템을 운영하는 입장과 사용하는 입장을 모두 접한 경험은, 무엇을 만들어야 하는지 구체적으로 생각하는 바탕이 되었습니다.

## 고객을 지원한 경험으로 온보딩 에이전트를 만들었습니다

클라우드 문서 시스템을 안내하기 위해 전국 지방연구소를 방문해 약 300명을 대상으로 대면 교육을 진행했습니다. 44장 교육자료와 발표 대본을 준비해 드라이브 설치부터 문서 이관과 영구보존까지 설명했습니다. 기능을 보여주는 것만으로는 충분하지 않았고, 사용자가 자신의 업무에 적용할 수 있도록 순서와 배경을 함께 설명해야 했습니다. 교육 후 받은 질문도 기록해 개발자들과 사용 편의성을 논의했습니다.

이 경험을 바탕으로 개인 프로젝트인 고객 온보딩 AI 에이전트를 만들었습니다. 가상의 고객 상황에서 문제를 진단하고 필요한 정보를 확인한 뒤, 안내와 교육 계획, 첫 활용 목표까지 이어지는 흐름을 설계했습니다. Next.js·TypeScript·Gemini API를 활용했고, AI가 13개 도구 중 필요한 도구를 선택하도록 구성했습니다. 설정 변경이나 고객 메시지, 개발 이슈 등록에는 사람의 승인을 두었습니다. 기획부터 설계, AI를 활용한 구현과 실행 검증까지 혼자 진행했으며, 가상 환경에서 업무 흐름을 확인하는 포트폴리오입니다.

## 실행 결과를 확인하며 빠진 과정을 보완했습니다

에이전트를 실행해 보니 기술 문제를 확인한 뒤 교육 계획이나 첫 활용 목표를 남기기 전에 보고서를 작성하려는 경우가 있었습니다. 제가 의도한 완료 기준과 AI가 판단한 완료 시점이 달랐던 것입니다. 첫 보고서 제출 단계에서 누락을 확인하고 보완하도록 조정했으며, 조치 후 재확인과 고객 회신 확인도 시나리오에 넣어 점검했습니다. 세 가상 고객 상황을 따라가며 도구 호출이 성공했는지뿐 아니라 사용자가 다음에 무엇을 할 수 있는지도 살펴봤습니다.

Claude Code를 활용한 블로그 자동화 프로젝트에서도 자료 조사와 출처 정리, 초안 작성, 검수를 업무 스킬로 나눴습니다. 분석 글 두 편과 동향 요약 한 편을 만들며 출처 번호와 원문이 맞는지, 초안과 최종본의 검수 기준이 섞이지 않았는지 확인했습니다. AI가 낸 결과를 바로 완성본으로 받아들이기보다, 어떤 과정을 확인해야 다시 사용할 수 있는지 배웠습니다.

## 해커톤에서 기획과 개발, 사용자 개선을 함께 경험했습니다

최근에는 청년의 근무 조건과 지원 변화를 비교하는 서비스 한끗의 팀장으로 해커톤에 참여했습니다. 매니페스트 AI를 활용해 PRD와 기능명세서, 와이어프레임을 마련하고, 팀이 함께 개발할 기준을 정리했습니다. 구조설계와 백엔드 지원을 맡아 아이디어를 실제 서비스로 구체화하는 과정에 참여했습니다. AI는 공고에서 근무 조건을 읽고 계산은 규칙표와 코드가 맡도록 역할을 나눈 팀 프로젝트입니다.

개발 후에는 Microsoft Clarity로 사용자의 행동을 살펴봤습니다. 뒤로가기를 반복하는 모습을 보고 시작 화면으로 바로 돌아갈 홈 버튼을 추가했고, 작동하는 요소로 오해해 클릭하던 장식 모션그래픽은 삭제했습니다. 이후 개선한 화면의 동작을 테스트했습니다. 정해 둔 기능을 완성하는 것에서 끝내지 않고, 실제 사용에서 혼란을 주는 부분을 찾아 수정한 경험이었습니다.

## 현장 경험을 개발에 활용하겠습니다

고객과 대화하며 요구사항을 정리하고, 시스템을 설명하고, 확인한 문제를 개발자에게 전달해 온 경험이 있습니다. 여기에 AI를 활용한 기획과 구현, 실행 결과 검증을 더해 가고 있습니다. 앞으로도 업무의 입력과 결과, 예외 상황을 먼저 파악하고 작은 기능부터 끝까지 만들어 확인하는 개발자가 되고 싶습니다. 사용자의 일을 이해하려는 태도와 직접 만들어 보는 실행력을 바탕으로, 현장에서 반복하는 일을 줄이는 도구를 만드는 데 기여하겠습니다.
