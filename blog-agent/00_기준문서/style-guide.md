# 스타일 가이드: 블로그 글 문체

> 블로그 글 2편(약 3,100자, 71문장)을 분석한 문체 지침입니다. 다른 AI 에이전트는 이 파일만 보고 같은 톤으로 글을 쓸 수 있습니다.
> 주제와 상관없이 적용합니다. 예문에 나오는 운동 관련 내용은 문장 구조를 보여주기 위한 것이므로, 소재는 쓰려는 주제에 맞게 바꿉니다.
> 표본이 적어 수치는 대략적인 경향으로만 참고합니다.

---

## 1. 핵심 요약

**한 줄 정의:** 경험 많은 동네 선생님이 어려운 개념을 쉬운 말로 풀어주고, 틀린 습관을 차분하지만 단호하게 짚어주는 글.

반드시 지킬 7가지:

1. 기본 문체는 정중한 합쇼체(`~습니다`)이고, 약 다섯 문장에 한 번꼴로 `~죠`를 섞습니다.
2. 개념을 말한 뒤 바로 `즉,`으로 쉽게 다시 풀어줍니다.
3. 주장 다음에는 반드시 `예를 들면,`으로 구체적인 사례를 듭니다.
4. 설명이 끝나면 `그러니,`로 독자가 할 행동을 결론짓습니다.
5. 단정한 뒤 `하지만,` 또는 `물론,`으로 예외와 단서를 답니다.
6. 쉼표를 많이 쓰고, 주어·조건절 뒤에서 호흡을 끊습니다.
7. 물음표, 느낌표, 물결표, 이모지, `ㅋㅋ`는 쓰지 않습니다. 감정은 어휘로만 드러냅니다.

---

## 2. 말투와 화자

- **화자:** 지식이 있는 실무자입니다. 권위를 내세우기보다 "제가 보기에는 이렇습니다"라는 태도로 말합니다. 첫 문장의 인사를 제외하면 자기 이야기는 거의 하지 않고, 글의 근거로만 `제가`를 씁니다.
  - `제가 생각했을 때, ~라고 볼 수 있습니다.`
  - `제가 ~에 대해서 이야기를 꺼내는 이유는, ~`
- **독자 호칭:** `여러분`을 쓰지 않습니다. 대신 `~하시는 분들`, `~을 가지신 분들`처럼 간접적으로 부르고, 동작에는 존칭 `~시`를 붙입니다.
  - `많은 분들이 간과하는`, `운동을 해보시면 아시겠지만`, `대부분 아마 기억 못하실 것이라고 생각됩니다`
- **온도:** 친절하지만 비위를 맞추지는 않습니다. 틀린 것은 틀렸다고 말합니다. 독자를 칭찬하거나 응원하는 말은 쓰지 않습니다.
  - `크게 운동이 되지 않습니다.`, `자세도 틀렸고, 가동범위도 작기 때문이죠.`
- **유머:** 웃기려 애쓰지 않습니다. 살짝 툭 던지는 정도입니다.
  - 과장된 구어 표현: `근육빵빵형님`, `죽어라 실시하신 분들`
  - 가벼운 비꼼: `물론 자신의 머리가 굉장히 좋아서 ~ 기억할 수 있다면 필요 없겠지만, 대부분 아마 기억 못하실 것이라고 생각됩니다.`

## 3. 문장 끝맺음

| 어미 | 비중(대략) | 쓰임 | 예시 |
|---|---|---|---|
| `~습니다 / ~합니다 / ~입니다 / ~됩니다` | 약 60~70% | 기본. 정의, 설명, 주장 | `원리는 간단합니다.` |
| `~죠` | 약 20% | 당연한 사실, 이유 덧붙이기, 공감 유도. 친근함의 핵심 | `정확히 기억하기 어렵죠.` |
| `~라고 볼 수 있습니다` | 가끔 | 핵심 주장을 조심스럽게 단정 | `대표적인 예라고 볼 수 있습니다.` |
| `~겠죠 / ~할 겁니다` | 가끔 | 추측, 가상의 상황 | `100개도 거뜬 하겠죠.` |
| `~할 필요가 있습니다 / ~하여야 합니다 / ~해주어야 합니다` | 가끔 | 지시, 권고 | `최대한 천천히 늘려줄 필요가 있습니다.` |
| `~하시기 바랍니다 / ~하시면 되겠습니다` | 글당 1회 내외 | 독자 행동 권유, 마무리 | `~ 운동을 하시면 되겠습니다.` |
| `~기 때문이죠 / ~기 때문입니다 / ~위함입니다` | 가끔 | 이유 설명 | `중요하기 때문이죠.` |
| `~라는 뜻이죠 / ~라는 것입니다` | 가끔 | 재정의, 강조 | |

**운용 규칙**

- `~습니다` 문장 2~4개를 쓴 뒤 `~죠`를 한 번 넣는 리듬을 유지합니다. 다만 `~죠`가 연달아 나오는 것도 허용합니다.
  - `물론, 12회 3세트만 죽어라 실시하신 분들은 훈련일지 필요없겠죠. 모든 훈련이 12회 3세트이니, 따로 적을 필요가 없죠.`
- 단락의 마지막 문장은 `~죠` 또는 `~합니다`로 맺는 경우가 많습니다.
- `~구요`는 드물게, 앞 문장을 살짝 뒤집을 때만 씁니다. `하지만, 무조건 크게 하면 또 안되구요.`
- `~요`체(`~해요`, `~거든요`, `~네요`)는 기본 어미로 쓰지 않습니다. 합쇼체가 흐트러집니다.
- 소제목에서만 평서형·명령형을 씁니다. `~한다.`, `~하라.`, 또는 명사로 끊기(`하나씩만.`). 본문에는 쓰지 않습니다.

## 4. 문장 호흡

- **평균 길이:** 문장당 약 40~45자입니다. 짧은 문장과 긴 문장의 차이가 큽니다.
- **교차 리듬:** 긴 설명문(70~150자) 뒤에 짧은 문장(10~25자)을 붙여 정리합니다. 이 교차가 문체의 핵심입니다.
  - `(긴 문장) ... 이두는 커지지가 않습니다. 자세도 틀렸고, 가동범위도 작기 때문이죠.`
  - `(긴 문장) ... 정체기를 그만큼 빨리 만나게 됩니다. 몸은 준비가 안 됐는데, ~ 이런 현상이 나타나죠.`
- **쉼표를 많이 씁니다.** 문법상 꼭 필요하지 않아도 말할 때 쉬는 자리에 찍습니다.
  - 접속사 뒤에는 거의 항상: `하지만,` `또한,` `그러니,` `즉,`
  - 조건절·때 표현 뒤: `~할 때,` `~하면,` `~함에도 불구하고,`
  - 주제어 뒤: `가동 범위란,` `제가 생각했을 때,`
- **긴 문장은 쉼표로 이어 붙입니다.** `A하면, B하고, C해서, D합니다.` 형태로, 말하듯 조건을 쌓아갑니다. 세미콜론이나 대시는 쓰지 않습니다.
- **단락은 짧습니다.** 1~5문장이고, 블로그 화면을 고려해 빈 줄로 자주 띄웁니다. 항목 설명만 예외적으로 한 덩어리로 길어질 수 있습니다.
- **괄호 보충:** 앞말을 더 정확히 고쳐 말할 때 괄호를 씁니다. `기록(훈련일지)의 중요성`, `무게를 고정시키고(혹은 몸무게 사용)`

## 5. 자주 쓰는 표현과 어휘

### 접속·전환어 (글의 뼈대)

| 표현 | 기능 | 빈도 |
|---|---|---|
| `그러니,` | 설명 끝, 행동 결론 도출 | 매우 높음 |
| `하지만,` | 앞 내용 제한, 반론 | 매우 높음 |
| `즉,` | 쉬운 말로 재진술 | 높음 |
| `예를 들면, / 예를 들어,` | 사례 제시 | 높음 |
| `또한,` | 사례·이유 추가 | 높음 |
| `물론,` | 예외 인정 | 보통 |
| `어찌됐든, / 어찌보면` | 정리로 전환 / 당연함 인정 | 보통 |
| `결론부터 말씀드리면,` | 핵심 선제시 | 글당 1회 이내 |
| `만약에`, `특히`, `그러나`, `우선` | 보조 연결 | 낮음 |

`그리고`는 거의 쓰지 않습니다. `또한,` 또는 쉼표 연결로 대체합니다.

### 즐겨 쓰는 부사

- **`최대한`** (가장 많이 쓰는 어휘. 짧은 글에서도 여러 번 반복합니다)
- `굉장히`, `훨씬`, `정확히`, `무조건`, `계속해서`, `점차`, `아주`, `엄청나게`, `대부분`, `거의`, `대충`, `정작`, `간혹`
- `매우`, `정말`, `너무`보다 `굉장히`를 씁니다.

### 입버릇 같은 문형

- `아무리 ~해도, ~` : `아무리 운동을 열심히 하더라도, ~ 좋아질 수가 없죠.`
- `~할 수가 없습니다 / ~지가 않습니다` (조사 `가`로 부정을 강조합니다) : `커지지가 않습니다.`, `찾아볼 수가 없습니다.`
- `~시면 아시겠지만, ~ / ~시면 알 수 있으시겠지만, ~` (독자의 경험에 기대는 문형)
- `~에 대해서`, `~함에 있어서`, `~을 진행하다`, `~을 실시하다` (살짝 격식 있는 표현)
- `~해버리면, ~해버리는 상황이 발생합니다` (나쁜 결과를 말할 때 `~해버리다`를 씁니다)
- `~하는 경우 / ~하는 상황이 오게 됩니다`
- `~해줘야 합니다 / ~해주는 것이 중요합니다` (`~해주다`를 많이 붙입니다)
- `혹시 몰라서 언급합니다.`, `어찌보면 당연한 말입니다.`
- `~라고 보는데`, `~으리라고 봅니다`, `~라고 생각됩니다` (완곡한 추정)
- `~분들이 대부분이죠`, `~하시는 분들이 계시죠`

### 구어적 포인트

딱딱해질 만하면 입말을 하나씩 섞습니다.

- 의태어·축약: `깔짝깔짝`, `쪼금씩`, `거뜬`, `빵빵`
- 관용 표현: `감을 잡다`, `죽어라`, `말도 안되는 일`

### 쓰지 않는 표현

- `~의 세계로 초대합니다`, `함께 알아볼까요?`, `~해보세요!`
- `여러분`, `꿀팁`, `핵심 포인트 정리!`
- 번역투·AI투: `~에 있어 핵심적인 역할을 합니다`, `다양한`, `효과적으로`, `중요한 것은 ~입니다`, `~뿐만 아니라 ~도`, `결론적으로`, `궁극적으로`
- 수사적 질문: `왜 그럴까요?` (표본에서 물음표는 0회입니다)

## 6. 글의 구조

### 도입부

첫 1~3문장 안에 주제를 바로 말합니다. 시의성 있는 이야기, 날씨, 안부 인사로 뜸을 들이지 않습니다.

**유형 A: 인사 + 예고 + 중요성**

```
안녕하세요. [필명]입니다.

오늘은 제가 포스팅하면서 자주 언급했던 [주제]에 대해서 설명해드리려고 합니다.
제가 생각했을 때, [주제]는 [분야]에서 가장 중요하면서도 기본이 되는 [개념]이라고 볼 수 있습니다.
아무리 [노력]을 하더라도, [주제]를 무시하면, [결과]할 수가 없죠.
```

**유형 B: 주제 선언 + 정의 + 쉬운 재진술 + 예시**

```
오늘의 이야기는 [주제] 입니다.
[주제]란, [정의]를 말합니다. 즉, [아주 쉬운 말] 입니다.
예를 들면, [일상적 사례], 그게 바로 [주제]가 되는 것이죠.
```

이어서 왜 다루는지 밝힙니다. `제가 ~ 이야기를 꺼내는 이유는, 중요하기 때문이죠. 또한, 많은 분들이 간과하는 부분이기도 하기 때문입니다.`

`중요하기 때문입니다`처럼 동어반복에 가까운 단순한 이유를 서슴없이 말하는 것도 특징입니다.

### 본문

**반복 단위 (주장 → 재진술 → 사례 → 결론)**

```
[주장]
즉, [쉬운 재진술]
예를 들면, [구체적 사례, 숫자 포함]
그러니, [독자가 할 행동]
```

- **결론 우선:** `결론부터 말씀드리면, ~`으로 답을 먼저 주고 이유를 뒤에 붙입니다.
- **단서 달기:** `결론 → 하지만 무조건은 아님 → 조건 제시 → 위반 시 나쁜 결과 → 사례` 순서입니다.
- **이야기로 열기:** 역사적 일화나 비유를 짧게 소개한 뒤 `~을 잘 설명해주는 대표적인 예라고 볼 수 있습니다.`로 연결합니다.
- **대비로 설명:** `A한 분들이 ~할 때, B한 분들은 ~`처럼 두 부류를 나란히 비교합니다.
- **숫자 사례:** 추상적 설명을 `10개 → 100개`, `40kg → 150kg`처럼 구체적 수치로 바꿉니다.
- **현실 관찰:** `~에서 가만 보시면 알 수 있으시겠지만, ~하시는 분들은 거의 찾아볼 수가 없습니다.`처럼 현장의 흔한 실수를 끌어옵니다.
- **번호 목록:** 실천 사항이 여럿이면 `1. 짧은 명령형 소제목.`을 달고 그 아래 2~6문장으로 풀어줍니다. 앞에 예고 문장을 둡니다. `~을 위해서는 아래 사항을 염두하고 ~하여야 합니다.`
- **화살표 도식:** 개념을 쪼갤 때 씁니다.

```
즉,
점진적 -> 쪼금씩
과부하 -> 부하를 늘려준다.
라는 뜻이죠.
```

- **자기 글 참조:** 이전 글을 작은따옴표로 언급합니다. `'기록(훈련일지)의 중요성'에서 언급했듯이, ~`

### 마무리

감상이나 인사 없이 **독자가 할 행동을 짧고 단호하게** 말하고 끝냅니다. `감사합니다`, `도움이 되셨으면 좋겠습니다`, `다음 글에서 만나요`, 해시태그는 쓰지 않습니다.

**유형 A: 핵심 한 문장 요약**

```
어찌됐든, 기억하실 포인트는 "[핵심 명령문]"라는 것입니다.
때에 따라서는 [예외]라는 것도 하긴 하지만, 우선 그런 것은 신경 쓰지 마시고, [행동]하시면 되겠습니다.
```

**유형 B: 마지막 항목의 행동 지시로 그대로 끝내기**

```
그러니, [행동]을 무조건 [해야만] 합니다. 그리고 [다음 행동]을 실시해주어야 합니다.
```

## 7. 그 외 눈에 띄는 특징

- **문장부호:** 마침표와 쉼표 위주입니다. 인용할 때는 큰따옴표, 글 제목에는 작은따옴표를 씁니다. 볼드, 표, 이모지는 거의 쓰지 않습니다.
- **소제목:** 번호 목록 외에는 소제목을 달지 않습니다. 빈 줄과 접속어로 전환합니다.
- **개념어 반복:** 대명사나 동의어로 바꾸지 않고 같은 용어를 그대로 반복합니다. 멋 부린 표현보다 명확함이 우선입니다.
- **한자어와 입말의 혼용:** `정체기`, `염두`, `적용`, `실시` 같은 딱딱한 말 옆에 `쪼금씩`, `깔짝깔짝`을 나란히 씁니다. 이 낙차가 개성입니다.
- **짧은 재확인:** `즉, 움직이는 범위 입니다.`처럼, 정의를 한 번 더 극단적으로 짧게 줄여 말합니다.
- **독자 예상 반론 선제 차단:** `한번에 늘리려고 하시는 분들은 거의 없으시리라고 보는데, 혹시 몰라서 언급합니다.`
- **과장 없는 단정:** 근거를 길게 대기보다 경험에서 나온 상식으로 단언합니다. 통계나 논문 인용은 쓰지 않습니다.

### 원문의 습관 중 따라 하지 않을 것

아래는 문체의 특징이 아니라 원문의 오탈자·비표준 표기로 보입니다. 새 글은 바른 표기로 씁니다.

| 원문 | 바른 표기 |
|---|---|
| `어찌됬든` | `어찌됐든` |
| `쪼금식` | `쪼금씩` |
| `중요면서도` | `중요하면서도` |
| `기본이되는` | `기본이 되는` |
| `염두하고` | `염두에 두고` |

띄어쓰기를 일부러 틀릴 필요도 없습니다. 원문에는 `바벨 컬 입니다`, `가동범위 / 가동 범위`처럼 띄어쓰기가 흔들리는 곳이 있으나, 새 글에서는 맞춤법을 지키고 용어 표기를 통일합니다.

## 8. 적용 예시

주제를 바꿔도 같은 톤이 나오는지 보여주는 예문입니다. 원문에 없는 주제로 작성한 것이므로 내용이 아니라 문체만 참고합니다.

**일반적인 AI 문체 (피할 것)**

> 독서 습관은 삶의 질을 높이는 데 핵심적인 역할을 합니다! 그렇다면 어떻게 하면 꾸준히 책을 읽을 수 있을까요? 지금부터 함께 알아보겠습니다.

**이 스타일로 쓴 글**

> 오늘의 이야기는 독서량 입니다.
> 독서량이란, 일정 기간 동안 읽은 책의 양을 말합니다. 즉, 얼마나 읽었느냐 입니다.
>
> 결론부터 말씀드리면, 독서량은 되도록이면 천천히 늘리는 것이 좋습니다.
> 하지만, 무조건 적게 읽으라는 말은 아니구요. 자신의 생활이 허락하는 내에서 최대한 꾸준히 읽어줘야 합니다.
> 예를 들면, 책을 안 읽던 분들이 한 달에 10권을 목표로 잡으면, 처음 며칠은 굉장히 열심히 읽지만, 2주도 안 돼서 책을 덮어버리는 상황이 발생합니다.
> 그러니, 하루 10쪽처럼 쪼금씩 늘려주는 것이 중요합니다.
>
> 서점에서 가만 보시면 알 수 있으시겠지만, 끝까지 읽을 책만 골라서 사시는 분들은 거의 찾아볼 수가 없습니다. 아무리 좋은 책을 많이 사도, 읽지 않으면 소용이 없죠.
>
> 어찌됐든, 기억하실 포인트는 "어떤 책을 읽든지 생활이 허용하는 범위 내에서 꾸준히 읽어라"라는 것입니다. 때에 따라서는 몰아서 읽는 방법도 있긴 하지만, 우선 그런 것은 신경 쓰지 마시고, 매일 읽는다는 생각으로 시작하시면 되겠습니다.

- [ ] 합쇼체가 기본이고, `~죠`가 대략 다섯 문장에 한 번 들어갔는가?

- [ ] 주장마다 `예를 들면,` 구체 사례(가능하면 숫자)가 있는가?

- [ ] 단정 뒤에 `하지만,` 또는 `물론,`으로 단서를 달았는가?
- [ ] 접속사와 조건절 뒤에 쉼표를 찍었는가?
- [ ] 긴 문장 뒤에 짧은 문장이 따라오는가?
- [ ] `최대한`, `굉장히` 같은 입버릇 어휘가 자연스럽게 들어갔는가?
- [ ] `?`, `!`, `~`, 이모지, `여러분`이 없는가?
- [ ] 입말 표현이 글에 한두 개 들어갔는가? (지나치게 많으면 가벼워집니다)

## 10. 블로그 프로젝트 추가 규칙

> 추가일: 2026-11-02 / 계기: 초안 v1 검수(`05_초안/검수결과_v1.md`)
> 위 1~9절은 원문 문체 분석이고, 이 절은 금융 IT 블로그에 맞춰 덧붙인 규칙입니다. 충돌하면 이 절을 따릅니다.

### 처음 나올 때 설명할 용어

독자에게 익숙해 보여도, 아래 용어는 처음 나올 때 괄호나 `즉,` 문장으로 한 번 풀어줍니다.

- 리전, 리전 내 추론, 교차 리전 추론
- SaaS, 망분리
- 서비스 이름(예: Knowledge Bases, CloudTrail)은 "무엇을 하는 기능인지" 한 구절로 설명합니다.

### 해석 표지

출처가 없는 인과 설명(`~때문입니다`)이나 일반화 문장에는 해석 표지를 붙입니다. 즉, 사실처럼 단정하지 않는다는 뜻이죠.

- 쓸 표현: `제가 보기에,`, `~라고 볼 수 있습니다`, `~으리라고 봅니다`
- 예를 들면, "규제는 넣는 정보를 기준으로 선을 긋습니다" 대신 "제가 보기에, 지금 금융 규제의 갈림길은 처리 위치보다 넣는 정보 쪽에 있다고 볼 수 있습니다"로 씁니다.

### 출처 표기

- 본문에는 `[A1]`처럼 짧은 번호만 붙입니다.
- 글 끝 출처는 표가 아니라 목록으로 씁니다. 모바일에서 URL이 잘리지 않게 하기 위함입니다.
  - 형식: `- [A1] 기관, 문서명, 날짜. URL`

### 소제목

- 명사형 또는 `~다`로 끝내고, 15자 이내로 씁니다. 예: `리전 내 추론이란`, `서울이라고 다 서울은 아니다`
- `~습니다`로 끝내지 않습니다. seo-guide.md의 "짧은 소제목 추가"와 2~3절의 소제목 규칙이 충돌하면 이 규칙을 따릅니다.

### 일반 정의 문장

- 망분리, SaaS처럼 널리 쓰이는 용어의 정의 문장은 출처를 붙이지 않아도 됩니다.
- 대신 발행 전 검수에서 사람이 정의가 맞는지 확인합니다.

### 미확인 표시

- 본문에는 `[확인 필요: X5]`처럼 `04_출처/확인필요_목록.md`의 번호를 함께 씁니다.

### 동향 요약에 적용하는 범위

- 동향 요약은 합쇼체, `~죠` 섞기, 금지 표현, 출처 표기 규칙만 지킵니다.
- `즉,` → `예를 들면,` → `그러니,` 반복 단위와 마무리 유형은 분석 글에만 씁니다.

### 작성자 몫의 자리 표시

`내 관점`처럼 작성자가 쓸 섹션은, 화면에 보이지 않는 주석으로 자리를 남깁니다.

- 형식: `<!-- 내 관점: 작성자 -->`
- `[작성자 작성 영역]`처럼 화면에 보이는 대괄호 문구는 쓰지 않습니다.
- 초안 상단에 `상태: 초안 v1` 같은 메타 줄을 넣지 않습니다. 버전은 파일 이름으로 구분합니다.
