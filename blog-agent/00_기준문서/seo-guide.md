# 네이버 블로그 SEO 가이드

> 조사 기준일: 2026년 11월 2일

## 먼저 읽을 내용

네이버는 **제목 글자 수, 키워드 횟수, 본문 글자 수, 이미지 장수의 공식 기준을 공개하지 않았습니다.** 네이버는 상위 노출을 보장하는 방법도 없다고 밝힌 것으로 전해집니다. 시중의 "제목 25자", "키워드 5회", "사진 10장"은 대부분 업계 관행이나 개인 경험입니다.

**조사 한계:** 이번 환경에서는 네이버 공식 블로그와 서치어드바이저 원문에 접속할 수 없었습니다. 공식 내용은 이를 날짜와 함께 인용한 2차 자료로 확인했으므로, 문구는 원문과 다를 수 있습니다. 중요한 결정 전에는 [출처](#출처)의 공식 링크를 직접 확인하세요.

| 표시 | 뜻 | 활용 |
|---|---|---|
| **[공식]** | 네이버 공식 안내를 인용한 2차 자료로 확인 | 지키는 것을 기본으로 삼기 |
| **[관행]** | 업계에서 흔히 쓰는 기준, 공식 근거 없음 | 출발점으로만 쓰고 직접 테스트 |
| **[미검증]** | 출처가 없거나 개인 경험에 기반한 주장 | 규칙으로 삼지 않기 |

### 핵심 원칙 7가지

1. 글마다 **독자, 상황, 검색 의도**를 하나로 정합니다.
2. **직접 겪은 절차, 결과, 시행착오**를 넣습니다.
3. 첫 부분에서 **결론을 먼저** 말합니다.
4. 제목과 소제목은 **내용을 정확하게** 대표하게 씁니다.
5. 키워드는 횟수를 맞추지 말고 **자연스러운 문장**에 넣습니다.
6. 이미지는 **본문과 직접 관련된 것**만 쓰고, 핵심 내용은 글로도 적습니다.
7. 대가를 받았다면 **명확히 표시**하고, 복사와 인위적 활동 조작은 하지 않습니다.

## 1. 제목 작성 규칙

### 글자 수

| 기준 | 내용 | 구분 |
|---|---|---|
| 공식 수치 | 없음. 명확하고 간결하게, 글을 대표하도록 작성 | [공식] |
| 업계 권장 | 15~25자 | [관행] |

실무에서는 15~30자를 초안 기준으로 삼고, 모바일 검색 결과에서 잘리지 않는지 확인하면 됩니다. 이 범위는 작성 편의를 위한 제안입니다.

### 키워드 위치

- 공식 위치 기준은 없습니다. 검색어는 자연스러운 문장 안에 쓰는 것이 원칙입니다. **[공식]**
- 핵심 키워드를 제목 앞쪽에 1회 넣는 방식이 널리 권장됩니다. **[관행]**
- 키워드 위치를 맞추느라 문장이 어색해진다면 자연스러움을 우선합니다.

### 피해야 할 제목 요소 **[공식]**

- 검색어 인위적 반복
- 지역명 나열
- 본문과 무관한 업체명이나 문구
- 의미 없는 특수문자
- 본문이 약속을 지키지 않는 낚시성 제목

금칙어 목록은 공개된 것을 찾지 못했습니다. 시중의 "금칙어 리스트"는 **[미검증]** 자료로 봅니다.

| 나쁜 예 | 좋은 예 |
|---|---|
| `강남 맛집 강남역 맛집 역삼 맛집 추천 BEST!!!` | `강남역 회식 장소 3곳, 12명 예약해 본 후기` |
| `다이어트 무조건 10kg 빠지는 비법` | `직장인 다이어트 8주 기록, 식단과 운동 시행착오` |

*위 표는 작성 형식을 보여주는 가상의 예시입니다.*

## 2. 본문 구조

### 도입-본론-결론 비율

**공식 비율은 없습니다.** 자주 인용되는 구체적 비율도 근거가 있는 자료를 찾지 못했습니다. 공식 근거가 있는 것은 소제목, 문단, 표로 읽기 쉽게 구성하라는 방향입니다. **[공식]**

작성 편의를 위해 아래 배분을 제안합니다. **근거 있는 규칙이 아니므로 글의 성격에 맞게 조정합니다.**

| 구간 | 제안 비중 | 담을 내용 |
|---|---|---|
| 도입 | 10~15% | 대상 독자, 문제, 결론 먼저 제시 |
| 본론 | 70~80% | 절차, 비교, 선택 이유, 결과, 시행착오 |
| 결론 | 10% 내외 | 핵심 요약, 다음 행동, 필요하면 관련 글 링크 |

### 소제목과 가독성

- 제목, 소제목, 문단 나누기를 적극 활용합니다. 개수 기준은 없습니다. **[공식]**
- 소제목만 훑어도 글의 흐름이 보이게 씁니다.
- 첫 부분에 결론을 쓰는 두괄식과 질문형 소제목이 AI 브리핑 인용에 유리하다는 주장이 있습니다. **[미검증]**
- 비교 정보는 표, 절차는 번호 목록으로 정리합니다. **[공식]** 방향에 부합하는 구성입니다.
- 3~5문장마다 줄을 바꾸면 모바일에서 읽기 편합니다. **[관행]**

### 본문에 넣을 내용 **[공식]**

- 읽을 독자와 상황(TPO)
- 직접 겪은 절차, 팁, 주의사항
- 고민한 대안과 선택 이유
- 실제 결과, 시행착오, 객관적 근거
- 인용할 때는 출처와 원문 링크
- 바뀐 가격, 영업시간 등의 최신화

### 글 길이

공식 기준은 없으며, 필요한 정보를 빠짐없이 담았는지가 기준입니다. **[공식]** "1,500자 이상", "2,000자 이상"은 **[관행]** 또는 개인 경험입니다. 분량을 맞추려고 내용을 늘리지 않습니다.

## 3. 키워드 밀도와 배치

| 주장 | 판단 |
|---|---|
| 공식 반복 횟수나 밀도 기준 | **없음** **[공식]** |
| 동일 키워드의 의도적 반복 | **스팸 유형** **[공식]** |
| 키워드 3~5회 | **[관행]**, 공식 기준 아님 |
| 키워드 밀도 1.5~3% | **[미검증]**, 근거 미제시 |

### 권장 배치

1. 제목에 핵심 키워드를 1회 넣습니다.
2. 도입부에서 주제를 자연스럽게 밝힙니다.
3. 필요한 소제목에만 키워드나 관련 표현을 넣습니다.
4. 본문에서는 독자가 실제로 쓰는 표현과 관련어로 풀어 씁니다.
5. 결론에서 필요하면 한 번 더 언급합니다.

**점검 방법:** 키워드를 소리 내어 읽어 어색하거나, 대명사로 바꾸는 편이 자연스럽다면 반복을 줄입니다. 키워드를 나열하지 말고 "무엇을, 누가, 어떤 상황에서, 얼마나"를 구체적으로 씁니다. 구체적이고 명확한 소재가 더 잘 노출될 수 있다는 것이 공식 안내의 방향입니다. **[공식]**

## 4. 이미지

### 장수

- 공식 기준은 없고, 수보다 본문과의 관련성이 기준입니다. **[공식]**
- 5장 또는 5~10장을 권하는 글이 많습니다. **[관행]**
- 글의 절차나 근거를 보여주는 데 필요한 만큼만 사용합니다. 후기나 체험 글은 직접 촬영한 사진을 우선합니다.

### 대체 텍스트와 이미지 정보

- 2023년 자료는 네이버 블로그에 Alt Text 작성 기능이 따로 없다고 설명합니다. 현재 에디터에서도 같은지 직접 확인이 필요합니다.
- 공식 안내의 핵심은 **이미지의 핵심 내용을 글로도 작성하라는 것**입니다. **[공식]**
- 따라서 이미지 앞뒤 본문에 사진 내용과 맥락을 적습니다. 에디터의 사진 설명란을 사용할 수 있다면 "제품 사진"보다 "12명 예약석에서 본 방 내부"처럼 구체적으로 씁니다.
- 일반적인 alt 텍스트 원칙은 키워드보다 설명을 우선하는 것입니다. 파일명도 내용을 드러내게 쓰면 관리에 도움이 됩니다. **[관행]**
- 이미지 안의 글자는 본문 텍스트를 대신하지 못하므로 중요한 정보는 글로 다시 씁니다.

### 대표 이미지 규격

**네이버 공식 픽셀 규격은 확인하지 못했습니다.** 아래는 비공식 제작 기준입니다.

| 항목 | 내용 | 구분 |
|---|---|---|
| 지정 방식 | 미지정 시 본문 최상단 이미지 사용, 사진의 [대표] 버튼으로 지정 | 비공식 자료 |
| 노출 비율 | PC 3:2, 모바일 1:1, 공유 환경 16:9 가능 | [관행], 2023년 자료 |
| 제작 방식 A | 16:9로 만들고 핵심 내용을 중앙 1:1 영역에 배치 | [관행] |
| 제작 방식 B | 1:1로 만들고 1000×1000px 등으로 저장 | [관행], 측정 기준 |

노출 비율은 달라질 수 있으므로, 발행 전에 PC와 모바일 미리보기에서 잘림을 확인합니다.

**대표 이미지 원칙 [공식]:** 글의 핵심을 보여주는 사진 한 장을 고르고, 텍스트가 많은 이미지, 분할 이미지, 핵심이 잘린 이미지는 피합니다.

## 6. C-Rank, D.I.A., AI 시대의 평가

### C-Rank: 블로그라는 출처의 신뢰도 **[공식]**

| 관점 | 평가 내용 | 실행 방향 |
|---|---|---|
| Context | 주제별 관심사의 집중도 | 블로그 글 대부분을 핵심 주제로 운영 |
| Content | 생산되는 정보의 품질 | 경험과 근거가 있는 글 작성 |
| Chain | 콘텐츠의 연쇄적 소비, 생산 | 저장, 공유, 언급이 자연스럽게 생기는 글 작성 |
| Creator | 블로그의 신뢰성과 인기도 | 장기적으로 일관된 주제와 품질 유지 |

주제 집중도는 블로그 전체 문서의 주제 분포로 계산한다고 전해집니다. 문서 수가 많다는 것만으로 유리한 것은 아닙니다.

### D.I.A.: 개별 문서가 검색 의도에 얼마나 맞는가 **[공식]**

| 요소 | 좋아하는 패턴 |
|---|---|
| 주제 적합도 | 검색 의도에 맞는 답을 담은 문서 |
| 경험 정보 | 직접 해 본 절차, 결과, 사진 |
| 정보의 충실성 | 질문에 답하는 데 필요한 정보가 충분함 |
| 문서의 의도 | 정보 제공, 후기, 의견의 목적이 분명함 |
| 상대적인 어뷰징 척도 | 키워드 조작, 광고 도배 신호가 적음 |
| 독창성 | 복사나 재가공이 아닌 고유한 내용 |
| 적시성 | 필요할 때 맞는 최신 정보 |

각 요소의 비중, 글자 수, 사진 수 기준은 공개되지 않았습니다. D.I.A.는 개별 문서 품질을 보며 작성 주기와 무관하다고 안내된 것으로 전해집니다.

### D.I.A.+: 의도와 실제 내용의 일치 **[공식]**

- 검색어가 경험, 의견, 리뷰 중 무엇을 찾는지 분석합니다.
- 문서 구조, 본문 텍스트, 이미지 정보에서 패턴을 추출합니다.
- 제목이 약속한 내용이 본문에 실제로 있는지 봅니다.
- 물품, 서비스, 금전 지원은 명확히 표시해야 합니다.

### 2024~2026년 변화

- **AI 작성 글:** AI 활용 자체를 이유로 불이익을 준다고 보지 않습니다. 생성 방식보다 결과물의 품질을 봅니다. 2024년에는 생성형 AI 활용 사실의 명시를 권고했습니다. **[공식]**
- **2025년 2월:** LLM으로 자동 생성 저품질 글과 경험 없는 광고성 글을 더 정밀하게 가려내도록 개선했습니다. **[공식]**
- **2026년 5~6월:** 네이버는 AI 시대 콘텐츠 작성 가이드와 실전편을 공개했습니다. 좋은 콘텐츠의 기본 원칙은 기존 SEO 기준과 같다는 설명이 전해집니다. **[공식]**
- **2026년 5월:** AI 도구 사용만으로는 패널티가 없으며, 기계적 생성이나 단순 요약 글은 AI 브리핑 인용에서 제외될 가능성이 높다는 내용이 2차 자료에 전해집니다. **[공식]**
- **2026년 5월 7일 전후:** 통합검색 노출이 줄었다는 마케터들의 보고가 있었지만, 검색 개편 공식 공지는 확인되지 않았습니다. **[미검증]**
- **블로그 지수:** "준최적 몇 단계" 같은 등급은 네이버 공식 개념이 아니라 외부 도구의 분류라는 분석이 있습니다. KPI로 쓰기보다 실제 키워드 노출과 유입을 확인합니다. **[관행]**
- **AuthGR, Next N Search 등:** 여러 글이 언급하지만 이번 조사에서 공식 원문으로 작동 방식을 확인하지 못했습니다. **[미검증]**

### 알고리즘이 선호하는 글

- 한 주제를 꾸준히 깊게 다룹니다.
- 정보 수집만으로는 쓸 수 없는 경험과 데이터가 있습니다.
- 제목의 약속을 본문이 지킵니다.
- 사진과 글이 같은 내용을 설명합니다.
- 대안 비교와 선택 이유가 있습니다.
- 오래된 정보를 갱신합니다.
- 출처와 대가성을 투명하게 밝힙니다.

## 7. 어뷰징과 스팸으로 볼 수 있는 행위

네이버는 "저품질"을 공식 용어로 사용하지 않는다고 알려져 있습니다. 다만 스팸 유형과 문서 품질 정책은 안내하고 있습니다.

### 공식 안내로 확인되는 금지 유형 **[공식]**

**콘텐츠 조작**

- 숨긴 텍스트
- 동일 키워드의 의도적 반복
- 다른 문서 복사 또는 짜깁기
- 문맥이 이어지지 않는 글의 반복 생성
- 템플릿이나 AI를 이용한 유사 콘텐츠 대량 발행
- 타인의 콘텐츠를 재가공한 자동 생성 글
- 사실로 오인될 수 있는 생성 이미지 등 피해를 유발하는 콘텐츠

**활동 조작**

- 여러 계정을 이용한 댓글, 방문, 추천 조작
- 매크로나 자동화 프로그램을 이용한 트래픽, 공감 조작

**신뢰 위반**

- 협찬, 원고료 등 대가성 미표시
- 과도한 광고 문구와 외부 링크
- 제조사 스펙 복사와 구매 링크 강조 위주의 글

**제목과 이미지**

- 낚시성 제목, 지역명 나열, 무관한 업체명
- 본문과 무관한 이미지 나열

저품질로 분류된 문서는 검색에 노출되지 않을 수 있습니다. **[공식]**

### 주의가 필요한 주장 **[미검증]**

| 주장 | 판단 |
|---|---|
| 광고 글 비율은 20~30% 이하 | 수치 근거 미확인. 정보성 글 중심 운영이라는 방향만 참고 |
| 하루 N개 초과 발행 시 제재 | 공식 제한 미확인. 다만 품질이 낮은 대량 발행은 위험 |
| 글을 삭제하면 패널티 | 공식 근거 미확인 |
| 300자 미만 글이 저품질 원인 | 수치 근거 미확인 |
| 체류 시간을 늘리면 된다 | 품앗이나 프로그램으로 조작하면 오히려 위험 |

### 발행 주기

꾸준히 쓰되 횟수를 채우려고 억지로 발행하지 않습니다. 정확히 일정한 간격으로 쓰면 오히려 어뷰징으로 오판될 수 있다는 안내가 전해집니다. **[공식]** 예약 발행 시각을 기계적으로 고정하지 않는 편이 안전합니다.

### 노출 문제가 의심될 때

1. 글 제목 전체를 검색해 노출 여부를 확인합니다.
2. 유입 경로와 키워드 변화를 비교합니다.
3. 복사성 글, 광고 글, 주제 이탈 글을 점검합니다.
4. 부족한 글은 정보와 경험을 보강합니다.
5. 회복까지 수주에서 수개월이 걸린다는 경험담이 있습니다. **[미검증]**

## 8. 발행 전 체크리스트

### 기획

- [ ] 독자, 상황, 검색 의도가 하나로 정리되었는가?
- [ ] 블로그의 핵심 주제와 맞는가?

### 제목과 본문

- [ ] 제목이 내용을 정확히 대표하고, 키워드가 자연스럽게 들어갔는가?
- [ ] 첫 부분에 결론이 있는가?
- [ ] 직접 겪은 절차, 결과, 시행착오가 있는가?
- [ ] 소제목, 문단, 표로 훑어 읽기 쉬운가?
- [ ] 키워드가 어색하게 반복되지 않는가?
- [ ] 수치, 가격, 일정을 확인했고 출처를 밝혔는가?

### 이미지와 태그

- [ ] 이미지가 본문과 직접 관련되는가?
- [ ] 이미지의 핵심 정보를 글로도 적었는가?
- [ ] 대표 이미지가 PC와 모바일에서 잘리지 않는가?
- [ ] 해시태그는 본문과 관련된 3~5개인가?
- [ ] 발행 주제를 올바르게 선택했는가?

### 정직성

- [ ] 협찬이나 대가성을 표시했는가?
- [ ] AI를 썼다면 직접 검토하고 경험을 더했는가?
- [ ] 광고 문구와 외부 링크가 과하지 않은가?

## 9. style-guide.md와 함께 쓸 때

두 지침이 충돌하는 지점은 다음처럼 처리하는 것을 권합니다.

| 항목 | style-guide.md | 이 가이드 | 처리 방법 |
|---|---|---|---|
| 소제목 | 번호 목록 외에는 거의 사용하지 않음 | 소제목 활용 권장 | 톤은 유지하고 짧은 소제목을 추가 |
| 도입부 | `결론부터 말씀드리면,` 사용 | 결론 우선 | 그대로 잘 맞음 |
| 키워드 | 같은 용어 반복 | 의도적 반복 주의 | 설명에 필요한 반복만 유지 |
| 근거 | 경험과 상식 위주 | 실제 결과와 객관적 근거 권장 | 경험에 수치, 기록, 출처를 추가 |
| 표 | 거의 사용하지 않음 | 표로 정리 권장 | 비교 정보에 한해 사용 |
