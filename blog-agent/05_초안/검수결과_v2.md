## v1 → v2 비교

| 구분 | v1 (규칙 1.0) | v2 (규칙 1.1) |
|---|---|---|
| 판정 | 수정 필요 | 초안 검수 통과 |
| 필수 미통과 | 3건 | 0건 (확인 필요 1건) |
| 표기 미통과 | 4건 | 0건 |
| `[확인 필요]` | 6곳, 목록 연결 없음 | 7곳, 모두 목록 번호와 연결 |
| 해석 단정 문장 | 1건 | 0건 (반례와 해석 표지 추가) |
| 용어 첫 설명 | 2개 | 8개 |
| 출처 형식 | 4열 표 | 목록 |
| 내부 문구 | 2건 | 0건 |

**무엇이 차이를 만들었나**

- 규칙 변경 때문에 판정이 바뀐 항목: `[확인 필요]`, `내 관점`. 내용은 그대로인데 초안 검수 기준이 생겨서 통과했다. 실제로 확인할 일이 줄어든 것은 아니고, 발행 전 검수로 넘어간 것이다.
- 글이 실제로 나아진 항목: 해석 단정, 용어 설명, 출처 형식, 내부 문구, 규정 이름 기재. 새 규칙이 구체적인 행동(무엇을 어떻게 쓸지)을 정해 준 항목들이다.

## 다음 개선 후보 (기준 문서 미수정)

1. **소제목 형식**: style-guide.md(`~한다.`)와 seo-guide.md(짧은 소제목)가 충돌하는데 기준이 없다. v2에서는 섞여 있다.
2. **일반 정의 문장의 출처**: 망분리나 SaaS 같은 정의에 출처를 요구할지 기준이 없다.
3. **`[확인 필요]` 번호 표기**: 본문에 `[확인 필요: X5]`처럼 목록 번호를 같이 쓰면, 초안 검수에서 목록과 맞춰 보는 단계가 자동화된다.
