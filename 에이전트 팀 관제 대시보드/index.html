    누가 무엇을 맡나

    역할 이름은 이해를 돕기 위해 붙였습니다. 실제로는 Claude Code 세션 하나가 스킬 두 개에 적힌 단계를 순서대로 실행하고, 각 단계에서 아래 문서를 읽고 파일을 남깁니다.

    /blog-analysis단계마다 사람 확인

    금융 고객 관점의 분석 글. 주제와 질문 → 조사 계획 → 조사 → 초안 → 초안 검수 → 발행 전 검수.

    /blog-trend한 번에 실행 후 보고

    주간 AI·클라우드 동향 요약. 직전 7일 공식 발표 3~5개를 모아 출처·초안·검수까지 멈추지 않고 진행합니다.

    역할하는 일읽는 기준남기는 파일

    지키는 규칙

    • ✓직접 연 원문에만 출처 번호를 붙이고, 검색 요약은 근거로 쓰지 않습니다.
    • ✓확인하지 못한 내용은 [확인 필요: X번호]로 남기고, 발행 전에는 0건이어야 합니다.
    • !블로그에 로그인하거나 게시하지 않습니다. 게시는 사람이 직접 합니다.
    • !기준 문서는 사용자 승인 없이 고치지 않고, 개선안은 보고에만 적습니다.

    실제 실행 기록 연결하기

    1. 1블로그 폴더에서 Claude Code로 /blog-trend 등을 실행하면, 훅이 07_실행기록/에 시각·도구·파일 경로를 한 줄씩 남깁니다. 프롬프트와 글 내용은 남기지 않습니다.
    2. 2실시간: 대시보드 폴더에서 node serve.mjs를 켜고 localhost:4173을 엽니다.
    3. 3나중에 보기: 위쪽 "실행 기록 열기"로 .jsonl 파일을 고르면 그 실행을 그대로 재생합니다.
