# 다른 프로젝트에 관제 대시보드 붙이기: 프롬프트

새 프로젝트 폴더에서 Claude Code를 열고, 아래 `---` 사이를 그대로 붙여 넣으세요.
`[대괄호]` 세 곳만 내 프로젝트에 맞게 바꾸면 됩니다. 모르는 칸은 비워 두면 에이전트가 폴더를 읽고 채웁니다.

---

이 프로젝트의 AI 에이전트가 일하는 모습을 보여 주는 **관제 대시보드**를 만들어 줘. 채용 면접관에게 시연하는 용도야.

**내 프로젝트 정보**
- 프로젝트 폴더: [예: C:\Users\admin\Desktop\내프로젝트]
- 에이전트를 부르는 방법: [예: /onboarding-run 스킬, 또는 "고객사 진단해 줘"라고 말하기]
- 사람이 꼭 확인하는 지점: [예: 고객 메일 발송 전, 설정 변경 전]

**참고할 완성본**
github.com/JIHOSW/jiho-agent 저장소에 같은 구조로 만든 완성본이 있어. 이 파일들을 가져와서 내 프로젝트에 맞게 고쳐 줘. 처음부터 새로 짜지 마.
- `에이전트 팀 관제 대시보드/index.html`: 대시보드 (단일 HTML, Tailwind CDN, Vanilla JS)
- `에이전트 팀 관제 대시보드/serve.mjs`: 실시간용 로컬 서버 (Node.js만 필요)
- `ai 블로그 자동화 에이전트/.claude/hooks/trace.mjs`: 실행 기록 훅
- `ai 블로그 자동화 에이전트/.claude/hooks/from-transcript.mjs`: 이미 끝난 실행을 기록으로 바꾸는 도구
- `ai 블로그 자동화 에이전트/.claude/settings.json`과 저장소 맨 위의 `.claude/settings.json`: 훅 등록

**순서**
1. 먼저 내 프로젝트를 읽어 줘. `.claude/agents/`, `.claude/skills/`, `CLAUDE.md`, README, 주요 스크립트를 보고 실제 역할과 단계를 정리해서 나에게 먼저 보여 줘.
   - 실제 파일에 없는 역할이나 단계는 지어내지 마.
   - 역할 이름을 이해하기 쉽게 붙일 때는, 실제로는 무엇이 실행되는지도 함께 적어 줘.
2. 내가 확인하면 대시보드를 고쳐 줘.
   - 가운데 오케스트레이터 노드와 역할 노드를 내 프로젝트의 실제 역할로 바꿔 줘. 사람 확인 지점은 주황색 노드로 따로 둬.
   - 시연용 재생 순서(TRACKS)를 내 스킬에 적힌 실제 단계 순서대로 바꿔 줘.
   - 탭 4개는 그대로 둬: Workflows(업무 흐름), Traces(단계별 시간), Usage(시간·토큰), Agents(역할 목록).
   - 저장소에 실제로 남아 있는 숫자(결과물 개수, 검수 기록 등)가 있으면 "실제 기록"으로 넣고, 그 숫자를 어느 파일에서 셌는지 함께 적어 줘.
3. 실행 기록 훅을 내 프로젝트에 맞게 고쳐 줘.
   - 내 에이전트(스킬)를 쓴 세션만 기록하게 해 줘. 같은 저장소의 다른 작업은 남기지 마.
   - 남기는 것: 시각, 도구 이름, 파일 경로, 접속한 사이트 주소, 검색어, 토큰 수. 프롬프트 본문, 파일 내용, 비밀번호·키, 내 컴퓨터의 전체 경로는 남기지 마.
   - 훅은 백그라운드로 돌리고, 오류가 나도 에이전트 작업을 막지 않게 해 줘.
   - 프로젝트 폴더를 직접 열 때와 저장소 맨 위 폴더에서 열 때 모두 같은 기록 폴더에 쌓이게 해 줘.
4. 대시보드가 기록을 역할로 나누는 규칙(`classify` 함수)을 내 프로젝트의 파일 경로와 도구 이름에 맞게 바꿔 줘. 예: 어떤 폴더에 쓰면 어떤 역할로 볼지.
5. 시험해 줘.
   - 가짜 기록 파일을 만들어 실시간 화면, "실행 기록 열기" 재생, 시연 재생이 모두 되는지 확인해 줘. 가짜 기록은 저장소에 넣지 마.
   - 휴대폰 폭(375px)에서 화면이 가로로 넘치지 않는지 확인해 줘.
6. 다 되면 Claude Artifact로 발행해서 링크를 주고, 저장소에도 저장해 줘. 커밋과 푸시는 내가 말할 때만 해 줘.

**꼭 지킬 것**
- 실행 시간, 토큰 수, "3일 → 5분" 같은 수치는 실제 기록이 없으면 지어내지 마. 화면에 "시연용 수치"라고 표시하고, 실제 기록을 열면 "실제 기록"으로 바뀌게 해 줘. 면접관이 예시 숫자를 진짜 측정값으로 오해하면 안 돼.
- 유료 도구나 설치가 필요한 라이브러리는 쓰지 마. 브라우저에서 바로 열리고 Netlify나 GitHub Pages에 그대로 올릴 수 있어야 해.
- 설명은 쉬운 한국어로 짧게 해 줘.

## 쓰는 법 요약

| 하고 싶은 것 | 방법 |
|---|---|
| 실행하는 동안 실시간으로 보기 | 대시보드 폴더에서 `node serve.mjs`를 켜고 `http://localhost:4173` 열기 |
| 끝난 실행을 공개 링크에서 보여 주기 | 대시보드 위쪽 "실행 기록 열기"로 기록 폴더의 `.jsonl` 파일 고르기 |
| 훅을 켜기 전에 돌린 실행을 기록으로 만들기 | `node .claude/hooks/from-transcript.mjs <대화 기록 .jsonl>` |

대화 기록은 보통 `C:\Users\<이름>\.claude\projects\<폴더 이름>\<세션 id>.jsonl`에 있습니다.
훅 설정은 **새로 연 세션부터** 적용됩니다.
