## v2에서 고칠 내용 (승인 후 반영)

1. "켜지 않으면 확인 없이 실행" → 출처를 [A15]로 바꾸고 "API 스키마로 정의할 때 기본값은 꺼짐"으로 범위를 좁힘
2. Quick 작업 목록 → "예로 드는 작업은 … 입니다"로 바꿈
3. AgentCore 세션 정책 → [A16]을 붙이고, 서울 지원과 "한 세션 안에서만 적용, 리전·계정 간 요청에는 적용 안 됨"이라는 단서를 추가
4. 용어 설명 추가: 프롬프트 주입(외부 입력에 숨긴 지시로 AI가 의도하지 않은 작업을 하게 만드는 공격), AgentCore(에이전트 실행·운영용 AWS 서비스), 세션(한 번의 연속된 작업 묶음)
5. "위험 요인으로 다뤄진다" 문장의 표현 강도를 낮춤

## 규칙 반영 제안 (기준 문서 미수정)

1. **검색 요약에서 본 내용을 원문 출처 번호로 달지 않는다**: 이번 오류의 원인이다. 검색 요약에서 본 내용이 실제로는 열어 보지 않은 페이지의 내용이었는데, 열어 본 다른 페이지 번호가 붙었다. 체크리스트 1절에 "출처 번호가 붙은 문장마다, 그 번호의 원문 페이지에 해당 내용이 있다" 항목을 추가하는 것을 제안한다.
2. **검수결과 파일 이름 충돌**: blog-analysis 스킬은 검수 결과를 `05_초안/검수결과_vN.md`로 쓰라고 하는데, 1편 파일과 이름이 겹친다. 이번에는 `에이전트승인_검수결과_v1.md`로 썼다. 스킬 4·5단계를 `<주제>_검수결과_vN.md`로 고치는 것을 제안한다.
3. **스킬 인식 위치**: 이번 세션은 상위 폴더에서 열려 스킬 호출이 실패했다. blog-agent 폴더에서 여는 것을 README나 프로젝트_개요에 한 줄로 남기는 것을 제안한다.
