# AI 직군 적성검사 에이전트

현재 상황과 관심 AI 영역에 따라 질문 갈래가 나뉘는 **대화형 AI 직군 적성검사**입니다.
약 40문항으로 역량·직업가치관·업무 스타일을 분석해 AI 직군 35개 가운데 맞는 직무 TOP 5와 준비 방법을 추천합니다.

▶ **웹에서 해보기**: https://jihosw.github.io/jiho-agent/career-agent/ <sub>(main 브랜치에 반영되면 자동 게시)</sub>

## 설계 결정 (문답으로 정한 내용)

| 항목 | 결정 |
| --- | --- |
| 대상 | 누구나 쓰는 공개용 |
| 직군 범위 | **AI 관련 직군만** (7개 영역 · 35개 직군) |
| 분석 축 | 강점·역량(9) · 직업가치관(6) · 성격/업무 스타일(4개 양극 축) |
| 동작 방식 | 규칙 기반 (AI API·서버 없음, 답변은 브라우저에만 저장) |
| 갈래 | 사용자가 고르는 2단계 분기: ① 현재 상황 → ② 관심 AI 영역(최대 3개) |
| 분량 | 약 40문항 · 10분 |
| 문항 형식 | 상황 선택형 · 양자택일 · 대화형(채팅) 말투 |
| 결과 | 점수 차트 · 추천 직군 TOP 5 · 링크 공유와 이미지·PDF 저장 |
| 배포 | GitHub Pages (`/career-agent/`) |

## 검사 흐름

```
① 현재 상황 ─ 학생 / 취업 준비생 / 개발·IT 현직자 / 비IT 직무 전환
   └ 문항 속 상황 표현({place}, {mate}, {work})과 결과의 '첫걸음' 조언이 달라짐
② 관심 영역 ─ 모델·연구 / AI 엔지니어링 / 데이터 / 제품·기획 / 비즈니스·현장 / 신뢰·안전·정책 / 크리에이티브 / 잘 모르겠음
   └ 고른 영역마다 직무를 좁히는 심화 문항 2개 추가 ('잘 모르겠음'은 방향 탐색 문항)
③ 역량 14문항 (상황 선택형)
④ 가치관 10문항 (양자택일)
⑤ 업무 스타일 8문항 (양자택일)
⑥ 관심 영역 심화 2~6문항
→ 결과: TOP 5 직군 + 이유·보완 역량·준비 로드맵 + 역량/가치관/스타일 차트
```

## 채점 방식

1. 문항의 각 선택지는 역량·가치관·스타일 점수를 더합니다(`data.js`의 `fx`).
2. 각 항목은 **이번 검사에서 얻을 수 있었던 최대치 대비 비율**(0~100)로 정규화합니다. 갈래에 따라 문항이 달라도 공정하게 비교하기 위해서입니다.
3. 직군마다 요구 역량·가치관 가중치와 스타일 목표값이 있고, 적합도는
   `역량 50% + 가치관 25% + 업무 스타일 25%`에 관심 영역(+), 심화 문항(+) 가산점을 더해 계산합니다.
4. 비IT 직무 전환자에게는 진입 난이도를 함께 보여 주고, 난이도가 높은 직군이면 내 결과에서 순위가 높은 '더 쉬운 직군'을 징검다리로 추천합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 시작·문답·결과 화면 |
| `style.css` | 포트폴리오 톤(진남색 + 청록 포인트), 라이트/다크 자동, 인쇄용 스타일 |
| `data.js` | 역량·가치관·스타일 정의, 상황·영역 갈래, 문항 48개, AI 직군 35개 |
| `engine.js` | 문항 구성·채점·설명 생성·공유 링크 인코딩 (화면과 분리된 순수 로직) |
| `app.js` | 채팅형 진행, 이전 답변 고치기, 이어서 하기, 결과 렌더링·공유·저장 |

## 수정하는 법

- **문항 추가/수정**: `data.js`에서 `choice(...)`(상황 선택형) 또는 `pair(...)`(양자택일)를 추가합니다. 선택지의 `fx`에 올릴 점수를 적습니다.
- **직군 추가**: `JOBS` 배열에 `c`(역량 가중치), `v`(가치관), `s`(스타일 -1~1), `diff`(진입 난이도), `steps`, `pf`, `tags`를 채워 넣습니다.
- **로컬 실행**: 빌드 과정이 없으므로 `index.html`을 브라우저로 열면 됩니다.
