# 녹음 파일 넣는 곳

| 파일 이름 | 들어갈 대사 | 나오는 화면 |
|---|---|---|
| `voice1.mp3` | 여보세요~? 김포 사는 김지호 씨입니까? 저는 대전 사는 오혜지인데요. | 두 번째 화면 |
| `voice2.mp3` | 오늘 우리 애기가 늦게까지 고생했다는 소식을 듣고 놀라서 전화 걸었습니다!! 얼른 마무리하고 지호랑 감사일기도 쓰고 행복하게 쉬어요!! 많이많이 사랑해!! | 세 번째 화면 |
| `voice3.mp3` (선택) | ㅋㅋ 아기, 오늘 진짜 고생했어. 웃는 목소리 듣고 싶어서 만들었어. 이제 푹 쉬어. | 마지막 쪽지 |

- 확장자는 `.mp3`, `.m4a`, `.wav` 모두 되지만, 공유 링크(claude.ai)에는 `.mp3`만 올라가요.
- 파일이 없으면 자막만 흘러가는 미리보기로 동작해요.
